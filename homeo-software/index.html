❓ Help — Demo Guide

How this demo works

  1. New Bill: search medicine → select potency → add → Save Bill. Stock decreases automatically.
  2. Vouchers: every saved bill becomes a numbered Sale Voucher (JV-0001…). View / reprint anytime.
  3. Inventory: add stock, edit prices, low-stock alerts at min level.
  4. Customers: unpaid balance is tracked per customer.
  5. Reports: sales, profit estimate, stock valuation.

Note: This is a web demo showing how the Windows software will look and work. The real .exe software runs natively on the shop PC — no internet, no domain, no hosting needed. Data stays on the PC.
