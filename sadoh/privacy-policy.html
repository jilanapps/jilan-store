🏴‍☠️ Privacy Policy — Sadoh!

Last updated: October 15, 2026

Sadoh! ("the Game") is published by Jilan Apps Official. We respect your privacy.

Data collection

The Game collects no personal data. There are no accounts, no sign-in, no analytics, no advertising, and no third-party SDKs. The Game works fully offline.

On-device storage

Game settings (such as sound on/off) are stored only on your own device using the app's private storage. Nothing is transmitted anywhere.

Permissions

The Game requests no sensitive permissions. Internet access is used only to load the latest game version from our website when available; the bundled offline copy is used otherwise.

Children

The Game is a family board game suitable for all ages and collects no data from anyone, including children.

Changes

If this policy changes, the updated version will be posted at this same address.
