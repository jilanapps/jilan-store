📋 Kaam kaise karta hai? (3 steps)

1

Register karein neeche diye form se. Admin approval ke baad aapko Reseller ID milegi.

2

Dashboard se kisi product ka "Share & Earn" dabayein — aapka unique link ban jayega. Use WhatsApp par share karein.

3

Jab aapke link se order deliver ho jaye, commission approve hogi. Phir withdraw karein!

📜 Terms & Commission Policy

  1. Approval zaroori: Register karne ke baad admin aapka account approve karega. Bina approval ke commission nahi milegi.
  2. Commission sirf delivered orders par: Order deliver hone aur return period guzarne ke baad commission approve hogi.
  3. Cancelled / returned orders: Jo order cancel ya return ho jaye, uski commission nahi milegi (ya wapas le li jayegi).
  4. Fake orders mana hain: Khud ke fake orders ya ghalat referral par account suspend ho sakta hai.
  5. Commission rate: Har product par alag ho sakti hai (fixed Rs ya %). Dashboard me har product ke sath likhi hogi. Default rate admin set karta hai.
  6. Withdrawal: Minimum amount admin set karega. Payout Easypaisa / JazzCash / bank transfer se, admin ki verification ke baad.
  7. WhatsApp orders: Jab customer WhatsApp par order kare to uske message me aapka Reseller ID hona chahiye taake admin match kar sake. Is me thori manual verification lagti hai — order foran count nahi hota.
  8. Qeemat tabdeeli: Product ki qeemat ya commission admin kabhi bhi badal sakta hai — purane pending commissions purani rate par hi rahenge.
  9. Data: Aapka naam, phone aur earnings record mehengfooz rahenge aur sirf aap aur admin dekh sakte hain.
