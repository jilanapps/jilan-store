Jilan Time Lock

Your lock password is the current time — it changes every minute.
At 09:25 PM the PIN is 0925. At 09:29 it is 0929.

Download APK (v1.0)
  1. Install the app and open it.
  2. Set a 4-digit backup PIN (it also unlocks, and turns the lock OFF).
  3. Allow Display over other apps when asked.
  4. Turn Time Lock ON. Done — the lock appears every time the screen turns on.

Overlay lock: it appears above your system lock screen and does not replace your system PIN. After the correct time PIN, your normal system lock still appears.
