❓ Help / Madad

📱 Shuru kaise karein (Phone par)

  1. Home par "Create New Video" dabayein
  2. Naam + kahani likhein, "Break into Scenes" dabayein
  3. Har scene ka prompt edit karein, characters attach karein
  4. Project save karein, phir "Assemble" se video banayein

🌐 Free deploy (GitHub Pages)

  1. GitHub par naya repo banayein (masalan jilan-ai-studio)
  2. Is jilan-ai-studio.html file ko index.html naam de kar upload karein
  3. Repo Settings → Pages → branch main select karein
  4. 2 minute mein link live: username.github.io/jilan-ai-studio/

🤖 AI Provider kaise connect karein

  1. Settings → Provider: "Custom API" chunein
  2. Apne provider ka Endpoint URL, Model naam aur API Key dalein
  3. "Test Connection" dabayein — sahi jawab aaye to connected!
  4. Phir scene par "Generate with AI" dabayein

⚠️ Limitations (Imandari se)

  • "Assemble Video" AI footage NAHI banata — local cinematic placeholders hain
  • Asli AI video ke liye API key + (aksar) paid plan chahiye
  • Face consistency AI model par depend karti hai
  • localStorage mein jagah mehdood hai — bari tasveerein compress hoti hain
  • Video .webm format mein download hoti hai
