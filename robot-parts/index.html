1

Arduino UNO R3

~Rs 2,000

Robot ka "dimagh" — isi par code dalta hai. Neeli board, USB wali.

2

L298N Motor Driver

~Rs 700

Motoron ko taqat deta hai — Arduino akela motor nahi chala sakta. Bara heatsink wala module.

3

HC-05 Bluetooth Module

~Rs 900

Phone se Bluetooth par robot ko control karne ke liye. Chhoti neeli chip, 6 pin wali.

4

Robot Car Chassis Kit (4WD)

~Rs 2,200

Gaari ka dhancha + 4 motors + pehiye — poora set ek dabbe me milta hai.

5

Jumper Wires (Male-Female)

~Rs 300

Hisson ko aapas me jorne wali rangeen taarein. Male-Female wali lein.

6

18650 Batteries + Holder

~Rs 700

Robot ki bijli — 2 batteries + holder. (Charger alag se le lein agar na ho.)
