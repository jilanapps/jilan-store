Jilan Store — Admin Setup

🔐 Firebase connect nahi hua.
Asli security ke liye Firebase zaroori hai. Bina iske admin secure nahi hoga — is liye nakli login nahi lagaya gaya.
Mukhtasar tareeqa (tafsil: FIREBASE_SETUP.md):
1️⃣ console.firebase.google.com par naya project banayein
2️⃣ Authentication → Email/Password ON karein, phir Add user se apna admin account banayein
3️⃣ Firestore Database → Create database (production mode)
4️⃣ Rules me admin/firestore.rules wala code paste karke Publish
5️⃣ Project settings → Web app se config copy karke admin/firebase-config.js me paste karein
6️⃣ Page refresh karein aur login karein ✅

🛡️ Security note

Firebase ki API key public hoti hai (ye normal hai). Asal hifazat Firestore Rules + Login se hoti hai — sirf login shuda admin hi cost, orders aur customer data dekh/badal sakta hai. Koi hardcoded password nahi hai.
